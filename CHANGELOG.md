# Changelog

## 0.1.0

Initial public Android release.

- Native Kotlin and Jetpack Compose application.
- Anime discovery, episode stream selection, playback, and downloads.
- YouTube metadata inspection, format selection, and downloads using the Android yt-dlp/FFmpeg runtime.
- Download management, history, and media publishing.
- Local video playback, picture-in-picture, and playback controls.
- Settings, appearance themes, and download destination selection.
